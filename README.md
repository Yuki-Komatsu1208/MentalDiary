# Mental Diary について

## プロジェクト概要
- ユーザのメンタルヘルスを管理することを目的とするローカルアプリです。
- 日々の状態入力と、その記録の振り返りを主な用途とします。

## 現在の主な機能
- 日々のステータス入力機能
- 一言メモ入力機能
- 入力内容の自動保存機能
- カレンダーで過去の記録を開く機能
- カレンダー上でのドーナツ表示による状態可視化機能

## 環境
### 開発環境
- フレームワーク: Flutter
- 言語: Dart

### 動作環境
- iOS を想定
- 外部接続なしのローカルアプリ
- 入力データはローカルに JSON 形式で保存

## 実行方法
### プロジェクトディレクトリ
- 実アプリ本体は `mental_diary/` 配下にあります。

### 主なコマンド
- 依存関係取得: `flutter pub get`
- テスト実行: `flutter test`
- iOS ビルド: `flutter build ios`
- 開発実行: `flutter run`

## ディレクトリ構成
### mental_diary/lib/Entities
- アプリ内で扱う状態データなどのエンティティを集約

### mental_diary/lib/Helpers
- JSON 保存、JSON 読み込みなどの補助処理を集約

### mental_diary/lib/Pages
- 画面の状態管理と画面遷移を担当するページを定義

### mental_diary/lib/UIDesigns
- 画面表示用の UI クラスを集約
- 日次入力画面用 UI
- カレンダーシート用 UI
- スライダー用 UI

## ユーザオペレーション
- 1. 情報登録
- USER: 当日、その日の心身状態を記録します。
- 記録項目: 気分、興味・関心、活力、睡眠の質、ストレス・不安を感じる、その日の一言メモ
- SYSTEM: 入力された情報をローカルファイルに JSON で自動保存します。

- 2. カレンダー上で表示
- USER: カレンダーを開き、ひと月分の状態を確認できます。
- SYSTEM: 日付の下にドーナツ型の可視化を表示し、その日の状態を直感的に確認できます。
- USER: 任意の日付を選択すると、その日の入力状態を読み込みます。

## 補足
- 現在は入力画面を起点とした構成です。
- デザインは黒基調のシンプルな UI を採用しています。
